# boom.me

Portfolio site: Next.js 15, React 19, Tailwind 4, fully static. A pixel ocean on a canvas follows the arrow keys and the scroll.

- `pnpm dev` runs it on http://localhost:3000
- `pnpm test` runs the Playwright tests, `pnpm typecheck` checks types
- All content (profile, skills, works) lives in `src/content/site.ts`
